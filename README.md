# Mon Projet Python - API RodiumAi (avec SDK)

Script interactif en ligne de commande utilisant le package officiel `rodiumai` (version >= 0.3) pour enchaîner Chat, Image et Vidéo.

## Installation
1. Installez les dépendances :
   ```bash
   pip install -r requirements.txt
2. Configurez le fichier .env à partir de .env.example en y insérant votre clé RODIUMAI_API_KEY.

3. Lancez le script :
python main.py
